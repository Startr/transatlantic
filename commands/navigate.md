description: Chart or work a navigation plan — decision cards in a TodoScope TODO.md
argument-hint: "<loose idea | path to chart TODO.md> [card name]"
---

Run the ta-navigate skill with $ARGUMENTS. If the argument is a loose idea, chart it: interview to name the destination, lay out decision cards in a TodoScope-convention TODO.md, sketch the fog into Backlog, and stop. If it names an existing chart, work it: claim one card by moving it to In Progress, resolve that one decision (talking to the human for HITL cards, never simulating them), record it as a decision file linked from Done, advance the frontier, and stop. Never resolve more than one card per session, research cards excepted.
