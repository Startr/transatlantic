Transatlantic

You don't have to grunt to save tokens.

Liner · Plain · Transatlantic · Aviation · Telegraph · Morse

Transatlantic gives your AI coding agent a prose register: six of them, on a ladder from classy humanized writing down to bare keywords. Each level is grounded in published research on how people actually read, and each is named for a way people once talked across an ocean.

The voice comes first. At Sage.is, makers of the Sage AI UI, the house writing guidelines have been minimal, earnest, and Hemingway-inspired for years: short declarative sentences, plain words, nothing cut that carries meaning. Transatlantic packages that register so your agent writes to it too. It is built on a fork of caveman, which proved that agents waste most of their words and contributed its measurement culture. We contributed the voice.

The headline: the default keeps full grammar and still lands in telegraph's savings band. The tokens were in the filler, never in the small words.

Built on evidence

Most "be concise" tools guess. We ran a 29-source research pass with adversarial fact-checking and built each level on what survived.

Plainer prose wins, measurably. A rewritten Veterans Affairs letter cut inbound support calls from 1,128 to 192. Even lawyers understand legalese worse than a plain rewrite of the same contract.

Syntax is the real enemy. Clauses folded inside clauses hurt recall more than jargon does. Every level splits nested sentences first and worries about word choice second.

Shorter and clearer are different axes. The ladder never pretends its tersest levels are its clearest; telegraph and morse are labeled as skim registers, honestly.

Readability formulas mislead. Against eye-tracking data, Flesch-style scores predict reading ease poorly. We design for common words in expected positions instead of chasing a grade number.

Every claim above carries a citation in the ladder document, including the ones we mark as unproven. When a rule is convention rather than evidence, the docs say so.

Install

Pre-release. Transatlantic is in active development and isn't on npm or a marketplace yet. Today's path is a local clone:

git clone <this-repo> transatlantic && cd transatlantic
node bin/install.js

Detects your agents and wires each one. Needs Node ≥18, safe to re-run, --uninstall removes everything it added. Switch levels with /transatlantic <level> or /ta <level>; say "normal mode" to stop. Every command in the docs is tested to resolve as written.

The honest-numbers rule is inherited and kept: these levels shrink output tokens only, the skill itself costs input tokens per turn, and the honest numbers page will tell you outright when this tool costs more than it saves. Benchmarks accept your API key, not our word.
